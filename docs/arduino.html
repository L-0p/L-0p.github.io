Distance Warning System

Using an ultrasonic sensor and LED as a proximity warning

← Home

Goal and interest area

I want to get better at analog input because I still struggle with it without guidance, including some of the basics. I chose this Arduino extension because it helps me practice building a circuit that does multiple things at one time. My current build measures distance with an ultrasonic sensor and uses an LED as a warning when something is too close.

New component and research

The new-to-me component in my build is an ultrasonic sensor. I used Arduino's Ping Ultrasonic Range Finder example to learn how a trigger pulse and an echo pulse can be used to calculate distance.

An ultrasonic sensor is not an analog input: it measures how long an echo takes to come back. A future version could add a photoresistor on A0 so I can practice reading a changing analog value.

Current circuit and wiring

Ultrasonic sensor
VCC → 5V rail; GND → GND rail; TRIG → D3; ECHO → D2
LED
D5 → 220 Ω resistor → LED anode; LED cathode → GND rail

The parts share the breadboard's 5V and GND rails. This lets more than one component use the same power and ground connections, even when the Arduino's 5V pin is already in use.

Prototype, troubleshooting, and peer support

At first, my ultrasonic sensor kept spewing out the same numbers. Matthew Ma helped me troubleshoot the wiring. He also helped me figure out how to power the LED without trying to use the already occupied 5V pin: I could share the 5V and GND rails on the breadboard.

Arduino code

This sketch makes the LED brighter when an object is closer and turns it off at 30 cm or farther.

// Pin definitions
const int trigPin = 3;
const int echoPin = 2;
const int ledPin = 5; // Must be a PWM pin (labeled with ~)

// Shorter distance range configuration (in centimeters)
const int minDistance = 2;   // Full brightness at 2 cm or closer
const int maxDistance = 30;  // LED turns off completely at 30 cm or farther

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // Clear trigger pin
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);

  // Send 10us trigger pulse
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // Read echo duration with 30ms timeout to prevent hanging
  long duration = pulseIn(echoPin, HIGH, 30000);

  // Calculate distance in cm
  int distance = duration * 0.034 / 2;

  // Constrain distance within our new 2cm–30cm range
  int clampedDistance = constrain(distance, minDistance, maxDistance);

  // Map distance to PWM brightness (0 to 255)
  int brightness = map(clampedDistance, minDistance, maxDistance, 255, 0);

  // Write PWM signal to LED
  analogWrite(ledPin, brightness);

  // Output readings to Serial Monitor
  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.print(" cm | Brightness: ");
  Serial.println(brightness);

  delay(100); // Short delay for stable readings
}

Future improvement

A warning system like this could help someone who is getting too close to a wall or another object. The LED and ultrasonic sensor give a visual warning. To make it more useful, I would add a piezo buzzer that blares when the object is dangerously close.

Reflection

This project is useful for someone starting with Arduino because it shows that one circuit can do multiple things at the same time. The skill I would rely on most if I kept developing it is debugging: a problem can come from a loose wire, a wrong breadboard column, a missing shared ground, or code that does not match the circuit.
