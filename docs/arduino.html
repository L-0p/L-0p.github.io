Distance Warning System

Extending an ultrasonic-sensor and LED circuit with a piezo buzzer

Goal and interest area

I want to get more confident with analog input. I can follow guidance, but I still struggle to understand the basics independently. This project lets me practice a circuit that does more than one thing at once: it measures distance with an ultrasonic sensor, shows a visual warning with an LED, and adds a sound warning when an object is dangerously close.

A distance warning could help someone avoid bumping into an object, such as while parking a bicycle in a tight space or moving equipment near a wall.

New component and research

My new component is a piezo buzzer, an output device that turns an Arduino signal into sound. I used Arduino's Built-in Examples page to find tone examples and learn how to start and stop the sound.

The ultrasonic sensor is not an analog input: it measures the time for an echo pulse to return. My next iteration will add a photoresistor on A0, which will let me practice reading a real analog value and adapting the LED warning to the light level.

Wiring plan

Ultrasonic sensor
VCC → 5V rail; GND → GND rail; TRIG → D9; ECHO → D10
LED
Anode → D6 through a 220 Ω resistor; cathode → GND rail
Piezo buzzer
Positive leg → D5; negative leg → GND rail

All components need a common ground. The breadboard rails let components share the 5V and GND connections instead of each part needing its own Arduino power pin.

Prototype and collaboration

My first ultrasonic-sensor setup kept printing the same distance numbers. Matthew Ma helped me troubleshoot the wiring. We checked that the trigger and echo pins were connected to the same pins named in the code and that the circuit had a shared ground. Checking one connection at a time helped me find the problem instead of guessing.

Matthew also showed me how to power the LED when the 5V pin was occupied: share the breadboard power and ground rails. Arduino code

const byte TRIG_PIN = 9;
const byte ECHO_PIN = 10;
const byte LED_PIN = 6;
const byte BUZZER_PIN = 5;
const float WARNING_CM = 25.0;
const float DANGER_CM = 10.0;

float readDistanceCm() {
  digitalWrite(TRIG_PIN, LOW); delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  unsigned long duration = pulseIn(ECHO_PIN, HIGH, 30000);
  if (duration == 0) return -1;
  return duration * 0.0343 / 2.0;
}

void setup() {
  Serial.begin(9600);
  pinMode(TRIG_PIN, OUTPUT); pinMode(ECHO_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  float distance = readDistanceCm();
  if (distance > 0 && distance < DANGER_CM) {
    digitalWrite(LED_PIN, HIGH); tone(BUZZER_PIN, 1600);
  } else if (distance > 0 && distance < WARNING_CM) {
    digitalWrite(LED_PIN, HIGH); noTone(BUZZER_PIN);
  } else {
    digitalWrite(LED_PIN, LOW); noTone(BUZZER_PIN);
  }
  delay(150);
}

Reflection

This system could help someone avoid an obstacle because the LED provides a visual warning and the buzzer can be heard even when the user is not looking at the circuit. To make it practical, I would test the distance thresholds, put it in a protective case, and make the sound pattern faster as an object gets closer.

The skill I would rely on most is debugging. A project can fail because of a loose wire, a wrong pin number, a missing shared ground, or code that does not match the circuit. I learned that I can make progress by checking one assumption at a time and using the Serial Monitor instead of guessing.
