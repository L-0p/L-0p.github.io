Distance Warning System

Using an ultrasonic sensor and LED as a proximity warning

Goal and interest area

I want to get better at analog input because I still struggle with it without guidance, including some of the basics. I chose this Arduino extension because it helps me practice building a circuit that does multiple things at one time. My current build measures distance with an ultrasonic sensor and uses an LED as a warning when something is too close.

New component and research

The new-to-me component in my build is an ultrasonic sensor. I used Arduino's Ping Ultrasonic Range Finder example to learn how a trigger pulse and an echo pulse can be used to calculate distance.

I learned that an ultrasonic sensor is not an analog input: it measures how long an echo takes to come back. Since analog input is still an area I want to improve, a future version could add a photoresistor on A0. That would let me read a changing analog value and make the LED warning respond to the surrounding light level.

Current circuit and wiring

Ultrasonic sensor
VCC → 5V rail; GND → GND rail; TRIG and ECHO → the digital pins named in my code
LED
Arduino output pin → 220 Ω resistor → LED anode; LED cathode → GND rail

The parts share the breadboard's 5V and GND rails. This is useful when the Arduino's 5V pin is already in use because one power connection can feed the rail and the other components can connect to that rail. Every part still needs a shared ground.

Code

This is the distance-warning logic I am using. Before my final submission, I will verify that the pin numbers and warning distance match my actual circuit.

const byte TRIG_PIN = 9;
const byte ECHO_PIN = 10;
const byte LED_PIN = 6;
const float WARNING_CM = 25.0;

float readDistanceCm() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  unsigned long duration = pulseIn(ECHO_PIN, HIGH, 30000);
  if (duration == 0) return -1;
  return duration * 0.0343 / 2.0;
}

void setup() {
  Serial.begin(9600);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  float distance = readDistanceCm();
  Serial.println(distance);
  digitalWrite(LED_PIN, distance > 0 && distance < WARNING_CM);
  delay(150);
}

Future improvement

A warning system like this could help someone who is getting too close to a wall or another object. The LED and ultrasonic sensor give a visual warning. To make it more useful, I would add a piezo buzzer that blares when the object is dangerously close, so the warning is easier to notice even if the user is not looking at the LED.

Reflection

This project is useful for someone who is starting with Arduino because it shows that one circuit can do multiple things at the same time. Sharing the 5V and GND rails makes it possible to connect more components without needing a separate power pin for each one.

The skill I would rely on most if I kept developing this idea is debugging. Being able to troubleshoot is powerful because a problem might come from a loose wire, a wrong breadboard column, a missing shared ground, or code that does not match the circuit. I learned to check one thing at a time rather than guessing.
